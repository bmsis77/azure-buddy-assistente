# Base de Conhecimento — Azure para Iniciantes

## 1. Microsoft Azure

O Microsoft Azure é uma plataforma de computação em nuvem da Microsoft.
Ele oferece diversos serviços para empresas e desenvolvedores, como
computação, armazenamento, bancos de dados, redes, segurança e análise
de dados.

A computação em nuvem permite utilizar recursos de tecnologia pela
internet sem necessariamente possuir e manter toda a infraestrutura
física.

Exemplo:
Uma empresa pode utilizar máquinas virtuais no Azure em vez de comprar
e manter servidores físicos próprios.

---

## 2. Computação em Nuvem

Computação em nuvem é o uso de recursos de tecnologia, como servidores,
armazenamento, bancos de dados e aplicações, por meio da internet.

Entre as principais características estão:

- acesso aos recursos pela internet;
- possibilidade de aumentar ou diminuir recursos conforme a necessidade;
- pagamento baseado no uso em diversos serviços;
- redução da necessidade de manter infraestrutura física própria.

---

## 3. IaaS

IaaS significa Infrastructure as a Service.

Nesse modelo, o provedor de nuvem oferece infraestrutura de tecnologia,
como máquinas virtuais, armazenamento e redes.

O cliente possui maior controle sobre a infraestrutura e também fica
responsável por administrar mais componentes.

Exemplo:
Uma empresa cria uma máquina virtual no Azure e instala nela o sistema
operacional e suas aplicações.

---

## 4. PaaS

PaaS significa Platform as a Service.

Nesse modelo, o provedor oferece uma plataforma para executar aplicações
sem que o usuário precise administrar toda a infraestrutura subjacente.

Exemplo:
O Azure App Service permite hospedar aplicações sem que o desenvolvedor
precise administrar diretamente o servidor físico.

---

## 5. SaaS

SaaS significa Software as a Service.

Nesse modelo, o usuário utiliza um software pronto disponibilizado pela
internet.

O provedor é responsável pela infraestrutura e pela manutenção do
software.

Exemplo:
Um usuário utiliza um sistema acessado pelo navegador sem precisar
instalar ou administrar os servidores responsáveis pela aplicação.

---

## 6. Azure Virtual Machines

Azure Virtual Machines permite criar máquinas virtuais na nuvem.

Uma máquina virtual pode ser utilizada para executar sistemas
operacionais e aplicações, de maneira semelhante a um computador ou
servidor físico.

Exemplo:
Uma empresa precisa executar uma aplicação em um servidor Windows.
Ela pode criar uma máquina virtual no Azure para executar essa aplicação.

---

## 7. Azure App Service

Azure App Service é um serviço de plataforma utilizado para hospedar
aplicações web.

Ele permite que desenvolvedores publiquem aplicações sem precisar
administrar diretamente a infraestrutura física dos servidores.

Exemplo:
Um desenvolvedor cria uma aplicação web e utiliza o App Service para
disponibilizá-la na internet.

---

## 8. Azure Blob Storage

Azure Blob Storage é um serviço de armazenamento de objetos.

Ele é utilizado para armazenar grandes quantidades de dados não
estruturados, como:

- imagens;
- vídeos;
- documentos;
- arquivos de texto;
- backups.

Exemplo:
Uma empresa possui milhares de imagens de produtos e pode armazená-las
no Blob Storage.

---

## 9. Azure Files

Azure Files fornece compartilhamentos de arquivos na nuvem.

Ele permite que aplicações e usuários acessem arquivos por meio de um
compartilhamento de arquivos.

Exemplo:
Uma empresa pode utilizar Azure Files para disponibilizar uma pasta
compartilhada utilizada por diferentes computadores.

---

## 10. Microsoft Entra ID

Microsoft Entra ID é o serviço de gerenciamento de identidades e acessos
da Microsoft.

Ele permite gerenciar usuários, grupos e acessos aos recursos.

Exemplo:
Uma empresa pode utilizar o Microsoft Entra ID para controlar quais
funcionários podem acessar determinados recursos do Azure.

---

## 11. Azure Monitor

Azure Monitor é um serviço de monitoramento que ajuda a coletar e
analisar informações sobre aplicações e recursos.

Ele pode ajudar a identificar problemas, acompanhar desempenho e
observar métricas dos recursos.

Exemplo:
Uma equipe pode utilizar o Azure Monitor para acompanhar o desempenho
de uma aplicação hospedada no Azure.

---

## 12. Azure Virtual Network

Azure Virtual Network permite criar redes privadas no Azure.

Ela possibilita organizar a comunicação entre recursos, como máquinas
virtuais e outros serviços.

Exemplo:
Uma empresa pode criar uma rede virtual para permitir que suas máquinas
virtuais se comuniquem de maneira controlada.

---

## 13. Regra de segurança do assistente

O assistente deve utilizar esta base de conhecimento como fonte principal
para responder às perguntas.

Quando uma informação não estiver disponível na base, o assistente não
deve inventar uma resposta.

Nessa situação, deve informar ao usuário que não possui informação
suficiente na base de conhecimento.

Informações que podem mudar com o tempo, como preços, limites,
disponibilidade de serviços ou configurações atuais do Azure, não devem
ser apresentadas como valores atuais sem uma fonte atualizada.
